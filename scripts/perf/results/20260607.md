## Refactoring summary

### pipeline.zig (546 → 518 lines)

`runHistorical` (165 lines) разбита на:
- `HistoricalConns.open()` — открывает 32 CQL-соединения (blocks/txs[3]/logs[6]/itxs[20]/contracts/comp)
- `HistoricalConns.deinit()` — единое место очистки всех соединений
- `HistoricalConns.saveArgs()` — формирует SaveArgs без дублирования полей
- `spawnHistoricalWorkers()` — spawn 64 workers в отдельной функции
- `abortAndDrain()` — очистка при fatal error (была inline в loop)

### main.zig (223 → 195 lines)

`main()` разбита на:
- `parseCli()` → `CliArgs{from, to}` — парсинг --from/--to
- `openRedis()` — открыть + auth + selectDb (используется 2 раза)
- `readCursorBlock()` — читает LATEST_PROCESSED_BLOCK_NUMBER
- `RealtimeContext.init/deinit` — группирует 6 realtime-объектов (conns, pool, redis, 3 clients)
- `delayMs()` — nanosleep helper
- `runRealtimeLoop()` — весь realtime while-loop
